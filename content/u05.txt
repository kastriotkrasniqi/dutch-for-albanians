@lesson Foljet e pozicionit
Në holandisht ka tri folje të veçanta për të treguar **ku ndodhet** diçka: **staan** (qëndroj në këmbë), **liggen** (shtrihem) dhe **zitten** (ulem). Zotërimi i tyre e bën holandishten tuaj shumë më natyrale.

@box (1.0, 0.96, 0.9)
  **Dallim i madh nga shqipja:** në shqip themi thjesht *«është»*: shishja *është* mbi tavolinë, libri *është* mbi tavolinë, macja *është* në karrige. Në holandisht nuk mjafton «zijn»: duhet të zgjedhim *si* ndodhet gjëja: në këmbë, e shtrirë apo e ulur.
@end
@table
| Folja | Shqip | Shembull |
| **staan** | qëndroj në këmbë | De fles **staat** op tafel. – Shishja është mbi ⏎ tavolinë. |
| **liggen** | shtrihem, jam i shtrirë | Het boek **ligt** op tafel. – Libri është mbi tavolinë. |
| **zitten** | ulem; jam brenda / i ⏎ mbërthyer | De kat **zit** op de stoel. – Macja është (ulur) në ⏎ karrige. |
@end

@h2 Kur përdoret cila folje
@table
| Folja | Përdoret për |
| **staan** | gjëra të gjata ose vertikale: shishe, ndërtesa, njerëz në këmbë |
| **liggen** | gjëra të sheshta ose horizontale: libra, letra, njerëz të shtrirë |
| **zitten** | njerëz dhe kafshë të ulur; gjëra «të mbërthyera» brenda ose te diçka |
@end

@h2 Si ta zgjedh folinë e duhur?
@box (0.91, 0.94, 0.98)
  Mendoni për formën dhe pozicionin e gjësë:
  **E gjatë dhe vertikale?** → **staan**
  **E sheshtë ose horizontale?** → **liggen**
  **E ulur ose brenda?** → **zitten**
@end
@h2 Shembuj të shpejtë
@table
| Holandisht | Shqip |
| De auto **staat** buiten. | Makina është jashtë. |
| De bloemen **staan** in de vaas. | Lulet janë në vazo. |
| De krant **ligt** op de bank. | Gazeta është mbi divan. |
| De sleutels **liggen** op tafel. | Çelësat janë mbi tavolinë. |
| Ik **zit** op de bank. | Unë jam ulur në divan. |
| De brief **zit** in de envelop. | Letra është në zarf. |
@end

@box (0.99, 0.93, 0.92)
  **Kujdes!** Mos përkthe fjalë për fjalë «është» me *is*. Gabim: *De fles is op tafel.* / *Ik ben op de bank.* → Saktë: *De fles staat op tafel.* / *Ik zit op de bank.* Në fillim duket e çuditshme, por dëgjoni foljet e pozicionit dhe shpejt do të ndjeni cilën të zgjidhni.
@end
@lesson Folja «staan» – qëndroj në këmbë
**Staan** përdoret për gjëra që janë në këmbë, vertikale: shishe, makina, lule, ndërtesa, si dhe për njerëz që qëndrojnë në këmbë. Folja është **e parregullt**: forma për «ik» është **sta**, jo «staan».

@table
| Përemri | Koha e tashme | Shqip |
| ik | sta | unë qëndroj / jam në këmbë |
| jij / je | staat | ti qëndron |
| hij / zij / het | staat | ai / ajo qëndron |
| wij / we | staan | ne qëndrojmë |
| jullie | staan | ju qëndroni |
| zij / ze (shumës) | staan | ata / ato qëndrojnë |
@end

@box (0.91, 0.94, 0.98)
  **Drejtshkrimi:** rrënja është **sta** (zanore e gjatë a). Kur shtohet **-t**, shkruajmë dy «a» që ta ruajmë tingullin e gjatë: *staat*, njësoj si *leer → leert*. Pas «jij» në pyetje, -t bie: *Sta jij daar?* (A qëndron aty?)
@end
@h2 Shembuj
@table
| Holandisht | Shqip |
| De fles **staat** op tafel. | Shishja është mbi tavolinë. |
| De auto **staat** buiten. | Makina është jashtë. |
| De bloemen **staan** in de vaas. | Lulet janë në vazo. |
| Ik **sta** bij de bushalte. | Unë qëndroj te stacioni i autobusit. |
| Wij **staan** in de rij. | Ne qëndrojmë në radhë. |
@end

@h2 Pyetje me «waar» (ku)
@table
| Pyetja | Shqip |
| Waar **staat** de fles? | Ku është shishja? |
| Waar **staan** de bloemen? | Ku janë lulet? |
| Waar **sta** jij? | Ku qëndron ti? |
@end

@box (0.99, 0.93, 0.92)
  **Kujdes:** «staan» është folje e parregullt: *ik sta* (jo *ik staan*). Mësojeni përmendësh si formë të veçantë.
@end
@lesson Foljet «liggen» dhe «zitten»
**Liggen** do të thotë «shtrihem, jam i shtrirë» (libra, letra, çelësa, njerëz në shtrat). **Zitten** do të thotë «ulem», por përdoret edhe për gjëra që janë brenda ose të mbërthyera diku.

@table
| Përemri | liggen | zitten | Shqip (liggen / zitten) |
| ik | lig | zit | shtrihem / ulem |
| jij / je | ligt | zit | shtrihesh / ulesh |
| hij / zij / het | ligt | zit | shtrihet / ulet |
| wij / we | liggen | zitten | shtrihemi / ulemi |
| jullie | liggen | zitten | shtriheni / uleni |
| zij / ze (shumës) | liggen | zitten | shtrihen / ulen |
@end

@box (0.91, 0.94, 0.98)
  **Drejtshkrimi:** te *liggen* dy «gg» bëhen një «g» në rrënjë (**lig**), dhe te *zitten* dy «tt» bëhen një «t» (**zit**). Në të dyja rastet «i» mbetet e shkurtër. **Kujdes:** me «jij» te *zitten* nuk shtohet -t: *jij zit*.
@end
@h2 Shembuj me «liggen»
@table
| Holandisht | Shqip |
| Het boek **ligt** op tafel. | Libri është mbi tavolinë. |
| De krant **ligt** op de bank. | Gazeta është mbi divan. |
| Ik **lig** in bed. | Unë jam shtrirë në shtrat. |
| De sleutels **liggen** op tafel. | Çelësat janë mbi tavolinë. |
@end

@h2 Shembuj me «zitten»
@table
| Holandisht | Shqip |
| Ik **zit** op de bank. | Unë jam ulur në divan. |
| De kat **zit** op de stoel. | Macja është ulur në karrige. |
| Wij **zitten** in de trein. | Ne jemi në tren. |
| De brief **zit** in de envelop. | Letra është në zarf. |
| Mijn telefoon **zit** in mijn zak. | Telefoni im është në xhep. |
@end

@h2 Pyetje
@table
| Pyetja | Shqip |
| Waar **ligt** mijn boek? | Ku është libri im? |
| **Zit** jij op de bank? | A je ulur në divan? |
| **Lig** jij in bed? | A je shtrirë në shtrat? (-t bie pas «jij»!) |
@end

@practice Ushtrime: lidh çiftet
@h2 A. Folja dhe kuptimi
Lidhni me vijë çdo kuti majtas me kutinë e duhur djathtas.

staan ⇥ karrigia

liggen ⇥ ulem

zitten ⇥ tavolina

de stoel ⇥ qëndroj në këmbë

de tafel ⇥ shtrihem

Jij ⇥ staat

@h2 C. liggen dhe zitten
